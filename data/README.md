# Data: sources, collection, and license notes

Every example is a triple **(LLM_name, LLM_Input, LLM_output)**. In the processed
CSVs the columns are `family` (the class label, i.e. LLM family), `model`
(fine-grained model name), `input` (first user prompt), and `output` (first model
response), plus `domain` (heuristic task tag), `prompt_id`, `battle_id`, `source`, and `split`.

## Primary source (used): LMSYS Chatbot Arena, 55k human-preference release
- URL: https://huggingface.co/datasets/lmarena-ai/arena-human-preference-55k (file `train.csv`, about 184 MB)
- What it is: 57,477 Chatbot Arena "battles" (Apr 2023 to Jan 2024 era models). Each battle has
  one user prompt answered by two anonymous models (`model_a`, `model_b`), plus a human vote.
  It is the training set of the Kaggle competition "LMSYS - Chatbot Arena Human Preference
  Predictions", built from the same platform as the TA-suggested `lmsys/chatbot_arena_conversations`.
- License: Apache-2.0 (dataset card). Public, **not gated** (no login needed).
- Collection by LMSYS: real users on chat.lmsys.org chatted with two models side by side
  and voted. LMSYS released the data after PII and moderation filtering.
- Citation: Chiang et al., 2024. *Chatbot Arena: An Open Platform for Evaluating LLMs by Human Preference.* arXiv:2403.04132.

## TA-suggested source (optional, gated): `lmsys/chatbot_arena_conversations`
- URL: https://huggingface.co/datasets/lmsys/chatbot_arena_conversations (33k conversations, 20 models)
- Status (checked 2026-10-05): **gated** (`gated: auto`). Downloading returns HTTP 401 without a
  logged-in Hugging Face account that has accepted the dataset terms. To use it, log in on
  huggingface.co, accept the terms on the dataset page, create a read token, `export HF_TOKEN=hf_...`,
  then run `python -m src.data.prepare_dataset --source arena33k` (or `--source both`; the
  pipeline de-duplicates identical responses).
- Kaggle TXD-22 (also suggested by the TA) needs a Kaggle account or API key. It is not wired in yet.

## Processing (src/data/prepare_dataset.py)
1. Keep only the **first turn** (first user message and first assistant reply) of each side of each battle,
   so each battle yields 2 examples.
2. Map `model` to `family` with `src/data/families.py`. **Only first-party models are kept**:
   GPT (OpenAI), Claude (Anthropic), Google (PaLM 2 and Gemini Pro), Llama (Meta Llama-2-chat,
   CodeLlama, LLaMA-13B), Mistral (Mistral-7B-Instruct, Mixtral-8x7B, Mistral-Medium).
   Community fine-tunes (Vicuna, Zephyr, WizardLM, OpenHermes, ...) are dropped because their family is ambiguous.
   Qwen and DeepSeek can be added with `--families`, but they only have about 2k and 0.8k examples.
3. Drop empty responses and responses under 20 characters. Drop prompts that are under 90% ASCII
   (a rough English filter). De-duplicate identical (family, output) pairs.
4. Tag each prompt's **domain** (coding, math, writing, or general) with keyword rules
   (`src/data/domains.py`). These tags are for RQ3 and are heuristic, so precision should be spot-checked.
5. **Balance**: undersample every family to the same size (default 4,000; Google is the smallest family, with 4,334 before balancing).
6. **Group split by prompt** (80/10/10, seed 42). Both responses to a prompt stay in the same split,
   and no prompt text appears in two splits. This matters for RQ2: it stops an input-only
   model from scoring well just by memorizing prompts.

See `data/STATS.md` for the filtering funnel, class counts per split, the family x domain table, and the models per family.

## Caveats to discuss in the report
- Era bias: these are late-2023 models. Some families' sampling windows on Arena differ
  (Gemini Pro only arrived in Dec 2023), so **prompt topics and time periods can leak family
  information**. This is a likely explanation if input-only classification beats chance (RQ2, iii).
- Within a family, several model versions are pooled, which makes intra-family style heterogeneous.
- Some responses self-identify ("As an AI developed by OpenAI..."). Use `--ablation mask_identity` to measure this effect.
- Prompts come from real Arena users. LMSYS filtered them, but we keep the text only for research and do not redistribute
  the processed CSVs (they are git-ignored and regenerated by the script).
